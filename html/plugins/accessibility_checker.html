Accessibility Checker

The accessibility_checker.min.js plugin checks the content against WCAG while you write. Click the accessibility button at the end of the toolbar, step through what it found, and use Fix where the rule offers one. One Undo reverts a fix. Each example in the editor is meant to be reported by the rule named above it. The first heading is in capital letters on purpose: it is what the custom DEMO1 rule in the script below reports.
